# PixelVault - Tienda Web con SCSS y Git

Proyecto de la asignatura **Diseño de Interfaces (2º DAW)** enfocado en el desarrollo de una arquitectura CSS modular con preprocesador **Sass (SCSS)** y flujo de trabajo colaborativo en **Git/GitHub** mediante ramas y Pull Requests.

## Integrantes del equipo
David Navarro y Antonio Chacon

##  Descripción del proyecto
PixelVault es una tienda online de videojuegos físicos y ediciones coleccionista compuesta por 4 páginas enlazadas (`index.html`, `catalogo.html`, `producto.html` y `contacto.html`), diseño responsive (breakpoint en 768px) y metodología BEM.
