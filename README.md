 PixelVault — Next-Gen Gaming Store

PixelVault es un proyecto de diseño de interfaces web enfocado en la creación de una tienda e-commerce moderna para ediciones físicas y de coleccionista de videojuegos de nueva generación.

Este proyecto ha sido desarrollado como práctica para el módulo de Diseño de Interfaces en 2º de DAW (Desarrollo de Aplicaciones Web).

Características del Proyecto

Diseño Moderno: Uso de tendencias de diseño actuales como Glassmorphism (cristal esmerilado) en la barra de navegación y tarjetas de productos.

Responsive Design: Adaptable a todo tipo de pantallas (móviles, tablets y escritorio).

Metodología BEM: Clases CSS estructuradas utilizando la convención de nomenclatura BEM (Bloque, Elemento, Modificador) para un código más limpio y mantenible (.card, .card__title, .button--primary).

Tipografía de Alto Impacto: Integración de Google Fonts (Plus Jakarta Sans y Space Grotesk) para una lectura óptima y una estética gaming premium.

Navegación Intuitiva: Menú principal e interacciones claras, con un pie de página (footer) completo con enlaces legales y de soporte.

📁 Estructura de Archivos

El proyecto consta de las siguientes páginas principales estáticas (HTML5):

index.html - Página principal (Hero banner, destacados, ventajas).

catalogo.html - Cuadrícula con todos los productos (6 tarjetas reutilizables).

producto.html - Ficha detallada de un producto (Ej. Cyber Odyssey 2099).

contacto.html - Formulario de contacto y datos de soporte.

ayuda.html - Sección de Preguntas Frecuentes (FAQ) utilizando etiquetas <details> y <summary>.

terminos.html - Condiciones legales de uso y devoluciones.

privacidad.html - Política de privacidad y tratamiento de datos.

css/main.css - Hoja de estilos principal que contiene todo el diseño visual.

 Tecnologías Utilizadas

HTML5: Estructura semántica (<header>, <main>, <section>, <article>, <footer>).

CSS3: Flexbox, CSS Grid, variables personalizadas (:root), transiciones y media queries.

⚙️ Instalación y Uso

No requiere de instalación mediante paquetes como npm. Para visualizar el proyecto:

Clona o descarga este repositorio.

Abre la carpeta del proyecto en tu editor de código favorito (ej. Visual Studio Code).

Lanza el archivo index.html en tu navegador o utiliza la extensión Live Server para ver los cambios en tiempo real.
